# Expense V2 - Personal Project Sem 6 FC

Objective 
- Expense tracking app for groups or families
- Provide a tracking app that allows expense tracking for accounts and groups

Target Customers
- Groups and families

Application Features and Description
- Visualize expenses for accounts, this can be per account, or per group
- When viewing own expenses, see summary or visualization with record of expenses
- When viewing group expenses, see percentage of expenses or money spent per person in group
- View expenses sorted by category

Tools and Resources
- Flutter and Dartlang (ui and logic)
- Firebase Firestore (cloud database)
